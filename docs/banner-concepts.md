# 시작 화면 ASCII 후보

최종 선택은 **1번 로고 + 3번 펭귄**입니다. 로고 왼쪽, 펭귄 오른쪽으로 조합해 메인 화면에 적용했습니다. `made by alloy`는 회색으로 표시합니다. 아래는 선택 과정에서 제시한 원래 후보입니다.

## 1. 슬랜트 로고

```text
    __    _____   ____  ___  __
   / /   /  _/ | / / / / / |/ /
  / /    / //  |/ / / / /|   /
 / /____/ // /|  / /_/ //   |
/_____/___/_/ |_/\____//_/|_|

   ____  __  __________________
  / __ \/ / / / ____/ ___/_  __/
 / / / / / / / __/  \__ \ / /
/ /_/ / /_/ / /___ ___/ // /
\___\_\____/_____//____//_/

         made by alloy
```

## 2. 서버 랙

```text
  .--------------------------------------------------------.
  | [::]                                              [::] |
  |--------------------------------------------------------|
  |                                                        |
  |                 L I N U X   Q U E S T                  |
  |                                                        |
  |--------------------------------------------------------|
  | [o] [o]    [||||||||||||||||||||||||||||]    [*]       |
  '--------------------------------------------------------'

                       made by alloy
```

## 3. 펭귄과 터미널

```text
       .--.
      |o_o |       L I N U X
      |:_/ |       Q U E S T
     //   \ \
    (|     | )        >_
   /'\_   _/'\
   \___)=(___/

       made by alloy
```

                      |        |
                 _____|________|_____
                /____________________\
