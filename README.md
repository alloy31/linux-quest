## 시작하기

Python **3.11 이상**, macOS 또는 Linux의 대화형 터미널, 실행 중인 Docker가 필요합니다.
별도로 설치할 호스트 Python 패키지는 없습니다. Windows 기본 터미널은 지원하지 않습니다.

```bash
git clone https://github.com/alloy31/linux-quest.git
cd linux-quest
python3 install.py
linux-quest
```

설치기는 `~/.local/bin/linux-quest`에 실행 링크를 만듭니다. 해당 경로가 PATH에 없다면
`./linux-quest` 또는 `python3 linux-quest`로 실행할 수 있습니다. 셸 설정은 자동 수정하지 않습니다.
이동한 체크아웃에서는 설치기를 다시 실행하거나 기존 링크를 확인하세요.

**ASCII 제목 → 시작하기 → 초급·중급·고급 → 짧은 도입 → 첫 실습**으로 이어집니다.
방향키·Enter 또는 숫자+Enter를 사용합니다. 작은 터미널은 작은 제목을 표시합니다.
`linux-quest`만 실행하면 기본으로 컬러 화면이 표시됩니다.

목표는 청록색 박스, 명령어는 노란색 예시, 힌트는 보라색, 완료는 초록색으로 구분합니다.
한글 문장과 긴 경로는 터미널 폭에 맞춰 줄바꿈합니다. 다음 미션·문제는 화면을 정리하고
새 번호와 제목으로 시작하며, 확인 문제의 해설은 Enter를 누른 뒤 다음 문제로 넘어갑니다.
색상 없이도 박스·제목·번호로 구분할 수 있습니다.
색을 끄려면 `linux-quest --color never`를 사용합니다. 게임 안내와 실습 프롬프트에 함께 적용됩니다.
환경에 맞춰 자동 감지하려면 `--color auto`를 사용하며, 이 모드에서는 `NO_COLOR`도 따릅니다.

첫 실습에서 Rocky Linux 8 이미지와 패키지를 준비하므로 인터넷과 다운로드 시간이 필요합니다.
미리 준비하려면 `linux-quest --build-lab`을 실행하세요. 준비 후의 실습·모의시험은
외부 인터넷 없이 작동하며, 네트워크 미션은 전용 내부망을 사용합니다.

## 플레이

```bash
pwd
ls /srv
cd /srv/archive/team
```

이것들은 게임이 흉내 내는 명령이 아니라 Docker 속 Bash에서 실행됩니다.
현재 디렉터리·환경변수·작업 제어가 유지되고 `vi`도 실제로 사용할 수 있습니다.
명령이 끝나 셸로 돌아오면 완료 조건을 검사합니다. 편집기 사용 중에는 끼어들지 않습니다.

| 난이도 | 안내와 과제 |
| --- | --- |
| 초급 | 필요한 개념·명령 예시와 작은 목표 |
| 중급 | 목표만 제시, 명령 조합과 추가 조건 |
| 고급 | 원인 조사와 여러 제약을 함께 해결 |

같은 결과를 만드는 여러 풀이를 인정합니다. 힌트는 개념 → 도구 → 풀이 순으로 열리며,
모든 난이도에서 사용할 수 있습니다. 일반 학습에는 제한 시간·목숨이 없습니다.

| 실습 명령 | 동작 |
| --- | --- |
| `quest mission` | 현재 목표와 남은 조건 확인 |
| `quest hint` | 다음 힌트 보기(최대 3단계) |
| `quest lesson` | 관련 개념 전체 보기(안내 사용으로 기록) |
| `quest check` | 즉시 채점·남은 조건 보기 |
| `quest answer 값` | 조사 미션에서 읽어낸 정보 제출 |
| `quest reset` | 현재 실습 환경을 초기화하고 재시도 |
| `quest skip` | 이번 시도를 건너뛰기 |
| `quest exit` | 미완료 미션을 남기고 메인 메뉴 |
| `Ctrl+]` | 실행 중인 명령과 별도로 게임 메뉴 열기 |

`exit` 또는 Ctrl+D로 실습 셸을 닫아도 재시도·건너뛰기·메뉴를 선택할 수 있습니다.
Ctrl+C는 실제 셸의 실행 작업을 중단합니다. Docker 연결 문제가 생기면 기존 완료 기록을
보존하고 재접속 경로를 제공합니다.

## 학습 구성

**10개 챕터 · 40개 미션(챕터별 종합 사건 포함) · 35개 개념 · 자체 제작 문항 177개**를 제공합니다.

| 챕터 | 내용 |
| --- | --- |
| 첫 접속 | 경로·목록·도움말, 리눅스 개요·역사·철학·배포판 |
| 자료실 정리 | 복사·이동·삭제·검색, 하드·심볼릭 링크 |
| 로그의 단서 | 텍스트 검색·정렬, 표준 입출력·파이프, 압축 |
| 잠긴 보관함 | 계정·그룹, 권한·소유권·umask |
| 달라진 작업 환경 | 셸 종류·따옴표·변수·환경 설정 |
| 멈추지 않는 작업 | 프로세스·시그널·nice, 작업 제어·예약 |
| 설정과 도구 | 실제 vi, 오프라인 RPM, Debian·소스 설치 비교 |
| 서버 재구성 | 설치·파티션·부팅·장치・인쇄의 모의 상황과 설정 파일 연습 |
| 연결 복구 | 실제 내부 HTTP, 주소·진단·인터넷 서비스, X 윈도 상황형 학습 |
| 최종 점검 | 가상화·클라우드·응용분야, 종합 인계 |

설치·부팅·물리 장치·실제 마운트·GUI는 **모의 상황**으로 명시합니다.
설정 파일 작성이나 상황 문제 통과를 실제 OS 설치·장치 설정 완료로 표시하지 않습니다.

미션 완료 뒤 관련 확인 문제와 해설을 제공합니다. 개념 미션은 틀린 내용을 다시 확인한 뒤
완료합니다. 힌트·오답은 복습 메뉴에서 다시 만날 수 있습니다.

- **기본 완료:** 미션 조건 충족
- **자력 해결:** 중·고급에서 힌트·브리핑 없이 해결
- **복습 통과:** 다른 실행 세션에서 다른 변형을 안내 없이 해결
- XP는 미션 최초 완료 시만 지급합니다. 난이도 변경·재시도는 기존 완료 기록을 지우지 않습니다.
- 챕터의 네 미션을 완료하면 구역을 복구하며, 사건 기록에서 발견한 단서를 다시 읽을 수 있습니다.

학습 메뉴의 모의시험은 1차 **50문항·60분**, 2차 **80문항·100분**입니다.
2차는 운영·관리 48문항과 활용 32문항으로 구성합니다. 총점 60점 이상,
2차는 각 과목 정답률 40% 이상을 적용하며 미응답은 오답입니다.
답 변경·이전/다음 이동·조기 제출·시간 종료 채점·문항별 해설을 지원합니다.
게임 등급과 모의시험 성적은 별개입니다.

## 저장과 실행 옵션

기본 저장 위치는 `${XDG_DATA_HOME:-~/.local/share}/linux-quest/progress.json`입니다.
원자적으로 저장하며 같은 저장 디렉터리의 중복 실행을 막습니다. 깨진 저장 파일은
자동 덮어쓰지 않습니다. 실습 파일은 임시 컨테이너에 있고, 이어하기는 **미완료 미션의 초기 상태**에서
재개합니다. 이전 완료·힌트·오답 기록은 유지됩니다.

```bash
linux-quest --doctor
linux-quest --check-content
linux-quest --list
linux-quest --mission 01-arrival --difficulty beginner
linux-quest --mission 07-edit --difficulty advanced
linux-quest --exam 1
linux-quest --data-dir /tmp/my-quest-practice
```

실습에는 개인 폴더·Docker 소켓을 마운트하지 않고 호스트 포트를 공개하지 않습니다.
컨테이너마다 메모리·CPU·프로세스 수를 제한합니다. 계정·패키지 미션에 필요한 sudo는
컨테이너 안의 지정 도구에 허용합니다. 게임 종료 시 자신이 만든 컨테이너와 내부망만 제거합니다.

## 개발·검증

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 linux-quest --build-lab
PYTHONPATH=src RUN_DOCKER_TESTS=1 python3 -m unittest discover -s tests -v
```

Docker 검사는 실습 26개 × 3개 난이도·변형 조합의 초기 실패·풀이 성공, 여러 권한 풀이,
일부 조건 실패, 컨테이너 격리·중단 복구를 확인합니다. PTY 검사는 실제 방향키 메뉴,
작은 터미널, 시작·힌트·초기화·이어하기, 셸 변수 유지, Ctrl+C/D, 실제 vi 편집을 확인합니다.
Docker 환경변수가 없으면 관련 검사는 명시적으로 skip합니다.

GitHub Actions도 콘텐츠 검사·이미지 빌드·실제 Docker/PTY 검사를 실행합니다.
콘텐츠 구조와 자동 검증 결과가 모든 문제의 교육적 완성도나 합격 가능성을 보증하지는 않습니다.

2026-10-27 로컬 검증: macOS ARM64, Python 3.15.0, Docker 29.8.2에서
Docker/PTY를 포함한 **26개 검사 전부 통과(건너뛴 검사 없음)**.
실습 풀이 검사는 26개 실습 × 3개 난이도·변형 조합, 총 78개 환경을 확인했습니다.
Windows 기본 환경, 실제 OS 설치·부팅·물리 장치는 검증 대상이 아닙니다.

같은 날 가독성 개선 후에는 총 **32개 검사**를 통과했습니다. 한글·긴 경로 줄바꿈,
색상 강제/해제, 미션·문제 전환 시 화면 초기화, 해설 확인 전 대기를 추가로 검증했습니다.

## 기준과 구조

2026년 리눅스마스터 2급을 기준으로 합니다. 기본 실습은 Rocky Linux 8이며 Debian 계열은
비교 설명·문제로 다룹니다. 문제는 자체 제작이며 공식 기출문제를 복제하지 않았습니다.
2027년 이후 응시에는 변경된 출제 환경을 별도로 확인해야 합니다.

- [KAIT 시험 안내·출제기준](https://www.ihd.or.kr/introducesubject1.do)
- [GNU Coreutils 매뉴얼](https://www.gnu.org/software/coreutils/manual/coreutils.html)
- [GNU Bash 매뉴얼](https://www.gnu.org/software/bash/manual/bash.html)
- [Rocky Linux 컨테이너](https://hub.docker.com/r/rockylinux/rockylinux)
- [Docker 보안·기본 seccomp 제약](https://docs.docker.com/engine/security/seccomp/)

`src/linux_quest/`의 campaign은 미션·초기 파일·조건·힌트, lessons/questions는 설명·평가,
runtime은 실제 Docker/PTY 연결, progress는 저장, app/ui는 화면과 학습 흐름을 담당합니다.
게임은 로컬에서 동작하며 계정·랭킹·원격 분석·유료 AI 연동은 없습니다.
