# 시작 화면 ASCII 후보

선택 전 미리보기입니다. 로고는 아직 교체하지 않았습니다. 모든 후보는 ASCII 문자로 구성했고, 공통 `made by alloy` 크레딧은 게임에서 회색으로 표시합니다.

## 1. 슬랜트 로고

```text
    __    _____   ____  ___  __
   / /   /  _/ | / / / / / |/ /
  / /    / //  |/ / / / /|   /
 / /____/ // /|  / /_/ //   |
/_____/___/_/ |_/\____//_/|_|

   ____  __  __________________
  / __ \/ / / / ____/ ___/_  __/
 / / / / / / / __/  \__ \ / /
/ /_/ / /_/ / /___ ___/ // /
\___\_\____/_____//____//_/

         made by alloy
```

## 2. 서버 랙

```text
  .--------------------------------------------------------.
  | [::]                                              [::] |
  |--------------------------------------------------------|
  |                                                        |
  |                 L I N U X   Q U E S T                  |
  |                                                        |
  |--------------------------------------------------------|
  | [o] [o]    [||||||||||||||||||||||||||||]    [*]       |
  '--------------------------------------------------------'

                       made by alloy
```

## 3. 펭귄과 터미널

```text
       .--.
      |o_o |       L I N U X
      |:_/ |       Q U E S T
     //   \ \
    (|     | )        >_
   /'\_   _/'\
   \___)=(___/

       made by alloy
```
